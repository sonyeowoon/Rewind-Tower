# 게임 기획서

## 1. 게임 개요

- 게임 제목: 색깔 주문 맞추기
- 장르: 기억력·순서 맞추기 게임
- 플레이 대상: 간단한 기억력 게임을 즐기고 싶은 모든 연령대의 사용자
- 실행 환경: PC 및 모바일 웹 브라우저
- 한 줄 콘셉트: 잠깐 나타난 색깔 순서를 기억하고 같은 순서대로 버튼을 눌러 5단계에 도전하는 게임

## 2. 제작 목적

- 플레이어가 느끼게 할 핵심 재미: 짧은 색깔 순서를 기억하고 정확히 맞혔을 때의 성취감
- 게임을 통해 제공할 경험: 단계가 올라갈수록 하나씩 길어지는 순서에 도전하며 부담 없이 기억력과 집중력을 시험하는 경험

## 3. 게임 진행 순서

1. 사용자가 시작 버튼을 누른다.
2. 빨강, 파랑, 초록 버튼 중 하나가 차례대로 강조되며 기억할 순서를 보여준다.
3. 사용자가 본 것과 같은 순서대로 색깔 버튼을 누른다. 정답이면 다음 단계로 넘어가고, 오답이면 즉시 종료된다.
4. 게임 결과를 확인한다.
5. 다시 하기 버튼으로 재시작한다.

## 4. 게임 규칙

- 조작 방법: PC에서는 색깔 버튼을 마우스로 클릭하고, 모바일에서는 손가락으로 터치한다.
- 점수 획득 조건: 한 단계의 순서를 모두 정확히 입력하면 10점을 얻는다.
- 점수 감소 조건: 점수는 감소하지 않는다. 오답을 누르면 현재 점수를 유지한 채 게임이 종료된다.
- 제한시간: 없음
- 게임 종료 조건: 색깔 순서를 한 번이라도 틀리거나 5단계를 모두 완료하면 종료된다.
- 각 단계는 단계 수만큼의 색깔로 구성한 새 패턴을 사용하며, 이전 단계의 패턴을 그대로 이어 붙이지 않는다.
- 2단계까지 순서를 보면 빨강·파랑·초록이 모두 최소 한 번 등장한다. 3~5단계는 각 패턴에 세 색깔을 모두 포함한다. 1단계에서 오답으로 끝나면 전체 색깔 등장 전에 종료될 수 있다.
- 승리 또는 목표 달성 조건: 1단계부터 5단계까지 모든 색깔 순서를 정확히 입력해 50점을 획득한다.

## 5. 화면 구성

### 시작 화면

- 게임 제목과 한 줄 설명
- 간단한 조작 및 규칙 안내
- 게임 시작 버튼

### 플레이 화면

- 현재 단계와 점수
- `순서를 기억하세요` 또는 `색깔을 눌러주세요` 상태 안내 문구
- 빨강, 파랑, 초록 색깔 버튼 3개
- 순서를 보여주는 동안 사용자의 입력을 막는 기능

### 종료 화면

- 승리 또는 실패 결과 메시지
- 최종 단계와 점수
- 다시 하기 버튼

## 6. MVP 핵심 기능

- [ ] 게임 시작
- [ ] 무작위 색깔 순서 생성
- [ ] 색깔 순서 차례대로 보여주기
- [ ] 사용자 입력과 정답 순서 비교
- [ ] 게임 종료
- [ ] 다시 하기

## 7. 추가 기능

- [ ] 최고 기록을 브라우저에 저장하기
- [ ] 단계가 올라갈수록 색깔 표시 속도를 빠르게 하기
- [ ] Suno로 제작한 배경음악과 소리 켜기·끄기 버튼 추가하기

## 8. 필요한 리소스

### 이미지

- 별도 이미지가 필요하지 않으며, 빨강·파랑·초록 버튼과 배경을 CSS로 제작한다.
- 시간이 남으면 제목 주변에 간단한 팔레트나 전구 이모지를 장식으로 사용한다.

### 효과음

| 구분 | 제작 도구 | 사용 시점 | 요구 사항 | 권장 파일명 |
|---|---|---|---|---|
| 배경음악 | Suno | 게임 시작 후 반복 재생 | 밝고 친근한 분위기의 보컬 없는 연주곡, 플레이를 방해하지 않는 낮은 음량, 자연스럽게 반복 가능한 구성 | `bgm-color-memory.mp3` |
| 빨강 버튼음 | ElevenLabs | 빨강 버튼이 강조되거나 눌렸을 때 | 짧고 또렷한 낮은 음의 전자음 | `color-red.mp3` |
| 파랑 버튼음 | ElevenLabs | 파랑 버튼이 강조되거나 눌렸을 때 | 빨강보다 조금 높은 짧은 전자음 | `color-blue.mp3` |
| 초록 버튼음 | ElevenLabs | 초록 버튼이 강조되거나 눌렸을 때 | 파랑보다 조금 높은 짧은 전자음 | `color-green.mp3` |
| 정답음 | ElevenLabs | 한 단계의 순서를 모두 맞혔을 때 | 짧고 밝은 성공 알림음 | `correct.mp3` |
| 실패음 | ElevenLabs | 잘못된 색깔을 눌렀을 때 | 부담스럽지 않은 짧은 오류음 | `wrong.mp3` |
| 승리음 | ElevenLabs | 5단계를 모두 완료했을 때 | 밝은 축하 느낌의 짧은 팡파르 | `victory.mp3` |

- 배경음악은 Suno의 Advanced 모드에서 Instrumental을 켜고 제작한다.
- 배경음악은 게임 시작 후 재생하며, GAME_OVER 상태에서는 멈추거나 음량을 낮춘다.
- 빨강·파랑·초록 버튼음은 서로 다른 높이로 제작해 소리만으로도 순서를 구분할 수 있게 한다.
- 효과음은 한 번에 짧게 재생하고, 빠른 연속 입력에도 지나치게 겹치지 않게 한다.
- 브라우저의 자동 재생 제한을 고려해 사용자가 게임 시작 버튼을 누른 뒤에 음악을 재생한다.
- 사용자가 배경음악과 효과음을 끌 수 있도록 소리 켜기·끄기 버튼을 추가할 수 있다.
- 오디오 파일은 프로젝트의 `Sounds/` 폴더에 저장한다.
- 배경음악과 효과음은 게임의 추가 기능으로 분류하며, 없어도 MVP 플레이는 가능해야 한다.

## 9. 프로젝트 완료 기준

- [ ] 게임이 브라우저에서 실행된다.
- [ ] 시작부터 종료까지 한 번의 플레이가 가능하다.
- [ ] 점수와 게임 규칙이 기획 내용과 일치한다.
- [ ] 다시 하기가 정상적으로 작동한다.
- [ ] PC와 모바일 화면에서 주요 요소를 사용할 수 있다.
