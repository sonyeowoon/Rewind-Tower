# Rewind Tower 게임 기획서

> 개정일: 2026-09-12 · 기준: 현재 구현된 10층 버전, 임시 저장 형식 2.
> 이 문서는 현재 게임의 기능과 운영 범위를 설명합니다. 구현 세부 사항은 [게임 설계서](game-design.md), 층별 구조는 [레벨 설계](level-design.md), 공개 준비 상태는 [배포 기록](deployment.md)을 참고합니다.

## 1. 게임 개요

| 항목 | 현재 기획 |
|---|---|
| 제목 | **Rewind Tower: 되감는 시계탑** |
| 장르 | 타일 기반 탑다운 수집·탈출 퍼즐 |
| 핵심 콘셉트 | 지나온 발자국을 역순으로 되감아 자신의 위치만 복귀시키고, 바뀐 세상을 활용해 탈출한다. |
| 전체 구성 | 서로 다른 크기와 구조의 10개 고정 스테이지, 순차 해금 |
| 난이도 | 1층 튜토리얼에서 시작해 경로 선택·발판·연속 열쇠·기준점 교체를 조합 |
| 플레이 시간 | 층당 짧은 탐험을 지향하되 후반의 큰 맵은 더 오래 걸릴 수 있음. 평균 플레이 시간은 사용자 테스트 전으로 미확정 |
| 조작 | 방향키 / WASD / 화면 화살표 이동, R / 화면 버튼 되감기 |
| 실행 | PC·모바일 웹, localhost 또는 HTTPS 정적 호스팅 |
| 계정 | 서버 없는 브라우저 로컬 계정, 게임용 닉네임과 4자리 PIN |
| 배포 | GitHub Pages·GPT Sites를 고려한 정적 출력 준비 완료. 실제 원격 배포는 미실행 |

게임 실행에 외부 런타임 라이브러리, 서버 API, 온라인 데이터베이스, 결제 또는 외부 CDN을 사용하지 않습니다. 메뉴와 게임은 한 HTML 문서 안에서 전환합니다. 맵은 전체 보기와 확대 보기를 제공하며, 큰 맵은 확대 후 스크롤할 수 있습니다.

## 2. 핵심 규칙과 되감기

1. 격자에서 상하좌우로 한 칸씩 이동합니다. 벽, 맵 밖, 심연과 무너진 발판으로는 이동할 수 없습니다.
2. 시간 톱니바퀴를 모두 수집하면 출구가 열립니다. 열린 출구 진입은 승리, 시간 균열 진입은 실패입니다.
3. 모래시계를 얻으면 되감기 1회를 추가하고 해당 칸이 최신 기준점이 됩니다. 보유 한도는 3회입니다.
4. 기준점 이후의 성공한 이동을 순서대로 기록합니다. 새 모래시계를 얻으면 기준점과 경로 기록을 새 위치부터 시작합니다.
5. 되감기는 직전 발자국부터 최신 기준점까지 **실제로 왔던 길의 역순**으로 이동합니다. 우회, 모서리와 같은 칸의 반복 방문도 그대로 재생합니다.
6. 되감기 한 번에 보유 횟수 1회와 50점을 소비합니다. 재생되는 칸 수만큼 이동 횟수나 점수를 추가로 차감하지 않습니다.
7. 획득한 아이템, 열린 출구·문과 무너진 발판은 복원하지 않습니다. 역재생 도중에는 중간 칸의 충돌·수집을 다시 실행하지 않아 무너진 다리도 잔상으로 통과합니다.
8. 무너지는 발판은 떠나는 순간 붕괴합니다. 그 위에서 되감아 떠나도 붕괴합니다.
9. 열쇠 1개로 잠긴 문 1개를 열고 열쇠를 소비합니다. 한 번 열린 문은 통과할 수 있습니다.
10. 기준점이 없거나 보유 횟수가 0이거나 이미 기준점에 서 있으면 되감기를 소비하지 않습니다.

재생 중에는 이동과 추가 되감기를 잠급니다. 긴 경로는 칸별 속도를 높이되 발자국을 생략하지 않습니다. 모션 감소 설정에서는 칸 사이 보간 효과를 끄고 순서는 유지합니다.

되감기의 게임 상태와 저장은 먼저 최종 기준점으로 확정합니다. 따라서 재생 중 저장·메인 이동·로그아웃·새로고침을 해도 중간 연출 좌표가 저장되지 않습니다. 화면을 벗어나거나 새 게임을 시작하면 이전 재생을 정리합니다.

## 3. 스테이지 구성

| 층 | 이름 | 컨셉과 핵심 퍼즐 | 크기 (가로×세로) | BGM |
|---:|---|---|---|---|
| 1 | 멈춘 입구 | 네 기둥의 열린 광장, 기본 이동·수집·되감기 학습 | 13×11 | 1 |
| 2 | 톱니 회랑 | 네 갈래 회랑, 왕복 단축과 새 기준점 선택 | 17×11 | 1 |
| 3 | 무너지는 다리 | 심연 위의 섬, 두 섬의 톱니 회수와 붕괴한 다리 귀환 | 15×13 | 2 |
| 4 | 잠긴 작업실 | 서고 → 작업실 → 연구실의 연속 열쇠 퍼즐 | 17×13 | 2 |
| 5 | 진자의 정원 | 팔각 순환로, 세 별실과 중앙 이중 잠금 | 19×15 | 3 |
| 6 | 뒤집힌 서고 | 수직 통로와 양옆 서가, 상부 회수 후 하부 출구 | 13×17 | 3 |
| 7 | 쌍둥이 금고 | 두 열쇠 방과 입구가 서로 다른 양쪽 금고 | 21×11 | 4 |
| 8 | 모래폭풍의 나선 | 중심에서 바깥으로 탐험, 긴 나선 역재생과 열쇠 지름길 | 17×17 | 4 |
| 9 | 분기하는 시간 | 대각선 상승로, 곁길 회수와 단계적 기준점 교체 | 19×13 | 5 |
| 10 | 시계탑의 심장 | 세 별실의 열쇠, 외곽 회랑과 마지막 세 겹 봉인 | 23×17 | 5 |

각 맵은 직접 배치한 고정 구조입니다. 처음에는 1층만 해금되고 다음 층은 직전 층을 클리어하면 열립니다. 1–2층은 되감기 없이도 풀 수 있고, 3–10층은 되감기가 필요한 퍼즐입니다. 전체 클리어는 **10층**에서 처리합니다. 이미 해금한 층은 다시 도전할 수 있습니다.

층 선택 카드에는 실제 지형의 미니맵, 구조 이름, 설명, 잠금·진행 중·완료 상태와 최고 점수를 표시합니다. 잠긴 카드는 비활성화합니다. 같은 층의 유효한 임시 저장이 있으면 이어하기와 처음부터 시작을 선택하고, 다른 층의 진행을 교체할 때는 확인합니다.

## 4. 점수·승패·결과

| 행동 | 점수 |
|---|---:|
| 스테이지 시작 | 1,000 |
| 톱니 수집 | +100 |
| 정상 이동 1회 | -3 |
| 되감기 1회 | -50 |
| 클리어 | +500 |

점수는 `max(0, 1000 + 수집 톱니×100 - 이동×3 - 되감기 사용×50 + 승리 보너스)`로 계산합니다. 실패한 이동과 사용할 수 없는 되감기는 점수·횟수를 변경하지 않습니다.

승패가 나면 이동을 멈추고 해당 판의 임시 이어하기를 삭제합니다. 결과에는 점수, 이동 수, 수집 수와 되감기 사용 수를 표시합니다. 승리 시 최고 점수를 갱신하고 다음 층을 해금하며, 다시 도전·스테이지 선택·메인 이동을 제공합니다. 마지막 층에서는 전체 결과 보기로 연결하고 10개 층의 최고 점수와 합계를 표시합니다.

시간 균열 외에 제한 시간이나 이동 수에 따른 자동 실패는 없습니다. 발판이나 되감기를 잘못 사용해 더 진행할 수 없으면 해당 층을 다시 시작할 수 있습니다.

## 5. 계정과 메뉴

- 닉네임은 앞뒤 공백 제거 및 정규화 후 2–12자이며 문자·숫자·밑줄·하이픈을 허용합니다. 중복 비교 시 대소문자를 통일합니다.
- PIN은 숫자 4자리이며 가입 시 한 번 더 확인합니다. 계정별 임의 salt와 PIN 해시만 저장합니다.
- 로그인은 닉네임 직접 입력 방식입니다. 실패하면 닉네임과 PIN을 확인하라는 공통 문구를 표시합니다.
- 첫 방문에 계정이 없으면 계정 생성 화면을 표시합니다. 새로고침 후에는 다시 로그인합니다.
- 계정 삭제는 현재 PIN 재확인과 삭제 동의가 필요하며 다른 계정의 기록은 유지합니다.

메인은 새 게임, 유효한 저장의 이어하기, 스테이지 선택, 조작법과 설정 및 기록 관리를 제공합니다. 새 게임은 1층의 새 판을 시작하며 해금·최고 기록을 초기화하지 않습니다. 기존 유효한 임시 진행을 교체할 때 확인합니다.

설정 모달에는 배경음·효과음 개별 음량, 저장 기록 삭제, 진행도 초기화와 계정 삭제가 있습니다. 저장 기록 삭제는 손상된 기록을 포함해 기록이 존재하면 가능합니다. 진행도 초기화는 임시 저장·해금·최고 기록을 지우고, 계정·튜토리얼·설정은 유지합니다. 상단에서 음소거, 조작법과 로그아웃에 접근합니다.

로컬 계정은 온라인 인증이 아닙니다. 기록은 같은 브라우저와 출처(origin)에만 남으며 다른 기기·브라우저·사이트 주소로 동기화되지 않습니다. 게임용 PIN을 사용하며, 브라우저 데이터 삭제 시 복구 기능은 제공하지 않습니다.

## 6. 튜토리얼·조작법·반응형

| 튜토리얼 단계 | 완료 조건 |
|---:|---|
| 1 | 한 칸 이동 |
| 2 | 첫 톱니 수집 |
| 3 | 첫 모래시계 획득 |
| 4 | 기준점에서 이동한 뒤 되감기 실행 및 재생 완료 |
| 5 | 목표·점수 안내 확인 |

첫 1층 시작 시 표시하며 요구 행동을 마친 뒤 다음 버튼으로 진행합니다. 필요한 이동·되감기 버튼을 강조하고, 현재 단계보다 앞선 주요 수집·되감기를 제한합니다. 완료나 건너뛰기를 계정별로 저장하며, 조작법에서 다시 시작할 수 있습니다. 이어하기에는 튜토리얼을 강제로 표시하지 않습니다. 튜토리얼은 게임 화면의 안내 카드이고 일반 모달이 아닙니다.

조작법 모달은 키보드·화면 버튼, 수집품, 발판, 열쇠·문, 균열과 점수 규칙을 설명합니다. 열려 있는 동안 게임 입력을 차단하며 닫기·바깥 클릭·Esc로 닫습니다.

맵과 플레이어는 각 층의 실제 행·열 수에 맞춰 표시합니다. PC와 모바일 모두 화면 방향 버튼을 제공하며, 모바일에서는 맵 아래에 조작부를 우선 배치합니다. 맵 확대 시 내부 스크롤을 사용하고 이동할 때 플레이어를 따라갑니다. 320×640, 360×800, 1366×768의 Chrome 화면 크기에서 가로 넘침·타일 비율·확대를 확인했습니다. 실제 모바일 기기 검증은 별도로 남아 있습니다.

## 7. 저장·이어하기

계정마다 임시 진행 한 개, 해금·최고 기록, 튜토리얼 완료 여부와 음량·음소거 설정을 분리해 저장합니다.

임시 저장에는 버전·소유자·스테이지·시각, 맵, 플레이어 위치와 방향, 기준점과 **순서가 있는 경로 기록**, 점수·이동·수집·되감기 횟수, 열쇠와 출구 상태를 포함합니다. 열린 문·붕괴 발판은 맵에 반영합니다. 애니메이션 진행도, 열린 모달과 일시적 안내는 저장하지 않습니다.

정상 이동·되감기 후, 새 판 시작 시, 메인·층 선택·로그아웃·페이지 이탈 및 숨김 시점에 플레이 중인 상태를 저장합니다. 수동 저장 버튼도 제공합니다. 자동 저장은 시각을 갱신하고 수동 저장은 성공 메시지와 저장음을 제공합니다.

유효한 현재 계정의 저장만 이어하기에 사용합니다. 다른 버전·소유자·잠긴 층·잘못된 좌표·불가능한 맵 변경·수치 불일치·연속되지 않은 경로는 거부합니다. 저장소 차단·용량 오류 시 현재 창의 메모리로 전환하고 지속 저장 불가를 안내합니다. 다른 창이 동일 계정의 진행을 변경하면 이전 플레이 세션을 해제해 오래된 기록의 덮어쓰기를 막습니다.

이번 개편의 임시 저장은 **버전 2**입니다. 이전 5층 버전의 이어하기는 호환되지 않습니다. 계정·설정·해금·최고 기록은 유지하며, 기존 5층까지 완료한 계정은 6층이 열립니다. 이전 맵의 최고 점수도 보존되므로 새 맵 기록과 함께 남을 수 있습니다.

## 8. 이미지·사운드와 시각 방향

네이비·황동·청록을 기본으로 한 시계장치 판타지 분위기를 유지합니다. 제공 이미지는 원본을 보존하고 실제 여백·배경에 맞춰 CSS 확대와 자르기를 적용했습니다. 정원·서고·금고·나선 등은 바닥 색조로 구분합니다.

배포에는 제공 이미지 15개와 새 배경 `assets/images/tower-abyss.png` 1개를 사용합니다. 심연 배경은 1536×1024로 추가 생성했으며 3·9층 공중 구간의 빈 공간 뒤에 보입니다. 되감기 잔상과 경로 강조, 실제 지형 미니맵은 CSS·DOM으로 구현해 별도 이미지가 필요하지 않습니다. 이미지 생성 참고와 실제 채택 현황은 [이미지 문서](image-prompts.md)에 기록합니다.

사운드는 제공 MP3 29개(배경음 7개·효과음 22개)를 모두 `assets/sounds/`에서 불러옵니다. 배경음의 원래 제작 계획은 Suno, 효과음은 ElevenLabs Sound Effects이며 현재 게임은 제공된 파일을 재사용합니다.

같은 곡을 사용하는 다음 층에서는 음악 위치를 이어가되 이전 효과음·예약된 효과·음량 감소는 정리합니다. 다른 곡으로 바뀌면 이전 배경음을 멈춥니다. 기본 음량은 배경음 35%, 효과음 70%이며 계정별로 조절합니다. 첫 사용자 입력 이후 재생하고, 재생 실패가 게임을 중단시키지 않도록 처리합니다.

## 10. 능동적 플레이 확장안

아래 요소는 현재 버전에 구현되지 않은 후속 개발안입니다. 퍼즐을 이해한 뒤 긴 통로를 이동하는 구간의 반복감을 줄이고, 되감기를 단순한 복귀 기능에서 능동적인 판단 수단으로 확장하는 것이 목적입니다.

실시간 반사 신경보다 **플레이어가 한 칸 움직이면 세계도 한 단계 반응하는 턴 방식**을 사용합니다. 플레이어가 멈춰 있으면 위험 요소도 멈추므로 PC와 모바일의 조작 조건이 같습니다. 기존 규칙대로 되감기는 플레이어 경로만 복원하며, 스위치로 바꾼 지형과 파수꾼의 위치는 되돌리지 않는 방향을 기본안으로 합니다.

### 우선순위 1 · 시간 스위치와 움직이는 다리

- 스위치를 밟으면 연결된 다리·문·벽의 상태가 전환됩니다.
- 연결 관계는 같은 색, 문양과 바닥 선으로 미리 보여줍니다.
- 스위치 상태와 바뀐 지형은 되감아도 유지합니다.
- `스위치 작동 → 막다른 길 수집 → 되감기 → 열린 새 경로 이용`을 기본 퍼즐 문법으로 사용합니다.
- 처음에는 스위치 하나와 구조물 하나만 소개하고, 후반에 다중 스위치와 순서를 조합합니다.

열쇠보다 여러 번 조작할 수 있어 맵의 상태 변화를 늘리고, 현재 되감기 규칙과 가장 자연스럽게 결합하므로 먼저 개발합니다.

### 우선순위 2 · 태엽 파수꾼

- 파수꾼은 미리 표시된 고정 순찰 경로를 따라 정상 이동 한 번마다 한 칸 이동합니다.
- 플레이어가 벽에 막힌 입력을 하거나 되감기 경로가 재생되는 동안에는 움직이지 않습니다.
- 파수꾼의 다음 이동 칸과 진행 방향을 화면에서 확인할 수 있게 합니다.
- 플레이어와 같은 칸에 도착하면 시간 균열과 같은 실패로 처리하는 것을 기본안으로 합니다.
- 되감아도 파수꾼의 위치는 유지하여, 이전과 다른 타이밍으로 통로를 통과할 수 있게 합니다.
- 첫 등장은 넓고 우회로가 있는 맵으로 제한하고, 좁은 통로에 여러 파수꾼을 동시에 배치하지 않습니다.

실시간 추격이나 공격 버튼은 추가하지 않습니다. 기존 한 칸 이동과 되감기만으로 안전한 경로와 타이밍을 판단하게 합니다.

### 우선순위 3 · 시간 톱니 콤보

- 톱니를 얻은 뒤 6회의 정상 이동 안에 다음 톱니를 얻으면 콤보가 이어집니다.
- 두 번째 톱니부터 단계마다 +25점의 콤보 보너스를 주고 최대 4단계로 제한합니다.
- 되감기는 정상 이동 횟수를 늘리지 않으므로, 되감기를 이용한 효율적인 수집도 콤보 전략에 포함합니다.
- 제한을 넘기거나 스테이지에 실패하면 콤보를 초기화합니다.
- 콤보는 클리어 조건이 아니며, 천천히 퍼즐을 푸는 플레이어에게 불이익을 주지 않는 선택 점수 요소입니다.

이미 클리어한 층에서 더 빠른 동선을 찾을 이유를 만들고, 톱니 수집 순간의 시각·사운드 피드백을 강화하는 용도로 사용합니다.

### 적용 순서와 스테이지 배치안

1. 시간 스위치의 단일 상태 변경과 저장·되감기 규칙을 구현하고 테스트 전용 맵에서 검증합니다.
2. 3–4층 중 한 곳에 단일 스위치를 소개하고, 5층 이후에 다중 스위치를 배치합니다.
3. 태엽 파수꾼 한 개와 경로 예고 UI를 구현해 넓은 4–5층에서 학습시킵니다.
4. 7층 이후에 스위치·파수꾼을 함께 사용하고, 10층에서 두 요소를 종합합니다.
5. 톱니 콤보를 전 층의 선택 점수 규칙으로 추가하되, 1층 튜토리얼 완료 전에는 표시하지 않습니다.
6. 실제 플레이 시간·실패 위치·재도전 횟수를 확인한 뒤 박동 발판과 도전 목표를 결정합니다.

기존 10개 맵을 한 번에 모두 수정하지 않습니다. 새 규칙을 한 층에서 소개하고 다음 층에서 조합하는 방식으로 적용하며, 변경된 맵은 자동 풀이와 되감기 필수 조건을 다시 검증합니다.
