# Rewind Tower 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **Rewind Tower: 되감는 시계탑** |
| 장르 | 타일 기반 탑다운 수집·탈출 퍼즐 |
| 한 줄 콘셉트 | 캐릭터 자신의 위치만 되돌리는 능력으로 시간 톱니바퀴를 모아 시계탑을 탈출한다. |
| 조작 | 방향키 또는 WASD 이동, `R` 되감기, 화면 버튼 |
| 플레이 시간 | 한 판 약 3~5분 |
| 전체 구성 | 난이도가 순차적으로 올라가는 5개 스테이지 |
| 목표 난이도 | 초보자도 튜토리얼만 보고 클리어할 수 있는 쉬운 난이도 |
| 실행 환경 | PC 및 모바일 웹 브라우저, GitHub Pages |
| 계정 방식 | 서버 없는 브라우저 로컬 계정 |

게임은 한 화면에서 진행한다. 설치형 외부 라이브러리, 서버, 온라인 데이터베이스와 결제 기능은 사용하지 않는다. 로그인은 실제 온라인 인증이 아니라 같은 브라우저 안에서 사용자를 구분하는 로컬 계정 방식으로 구현한다.

### 로컬 로그인 방식의 한계

- 계정과 저장 데이터는 현재 브라우저에만 존재한다.
- 다른 기기나 다른 브라우저에서는 같은 계정으로 이어할 수 없다.
- 브라우저 데이터를 삭제하면 계정과 진행 기록도 함께 사라질 수 있다.
- 온라인 서비스용 보안 로그인이나 개인정보 보호 기능으로 사용할 수 없다.
- 사용자는 개인정보가 아닌 게임용 닉네임과 4자리 PIN을 사용한다.

## 2. 핵심 규칙

1. 플레이어는 격자형 맵을 한 칸씩 이동한다.
2. 벽은 통과할 수 없다.
3. 시간 톱니바퀴를 모두 모으면 출구가 열린다.
4. 모래시계를 획득하면 되감기 1회를 얻고 그 위치가 시간 기준점으로 저장된다.
5. `R`키를 누르면 되감기 1회를 소비해 기준점으로 돌아간다.
6. 되감기는 플레이어의 위치만 바꾸며, 이미 획득한 아이템과 열린 출구는 되돌리지 않는다.
7. 열린 출구에 도착하면 승리하고, 시간 균열에 닿으면 실패한다.
8. 스테이지를 클리어하면 다음 스테이지가 해금된다.
9. 이미 클리어한 스테이지는 스테이지 선택 화면에서 다시 플레이할 수 있다.

막다른 길 끝의 톱니바퀴를 얻은 뒤 기준점으로 돌아오는 구조를 통해 되감기가 퍼즐 해결 수단이 되도록 한다.

## 3. 스테이지 구성

| 스테이지 | 이름 | 핵심 학습·퍼즐 | 기본 상태 |
|---:|---|---|---|
| 1 | 멈춘 입구 | 이동, 톱니바퀴 수집, 출구 | 처음부터 해금 |
| 2 | 톱니 회랑 | 막다른 길에서 모래시계와 되감기 사용 | 1 클리어 후 해금 |
| 3 | 무너지는 다리 | 한 번 지나가면 무너지는 발판과 되감기 | 2 클리어 후 해금 |
| 4 | 잠긴 작업실 | 시간 열쇠를 얻고 되감아 잠긴 문 개방 | 3 클리어 후 해금 |
| 5 | 시계탑의 심장 | 수집, 발판, 열쇠, 균열과 제한된 되감기 종합 | 4 클리어 후 해금 |

- 각 스테이지는 한 화면 안에 표시되는 고정 크기 맵이다.
- 한 스테이지의 예상 플레이 시간은 약 3~5분이다.
- 스테이지 1은 튜토리얼을 겸하며 실패 위험을 낮게 만든다.
- 후반으로 갈수록 톱니바퀴 수와 경로 선택은 늘지만 조작 자체는 바뀌지 않는다.
- 스테이지 5를 클리어하면 전체 게임 완료 결과를 표시한다.

## 4. 점수 규칙

| 행동 | 점수 변화 |
|---|---:|
| 게임 시작 | 1,000점 |
| 시간 톱니바퀴 획득 | +100점 |
| 정상 이동 1회 | -3점 |
| 되감기 1회 사용 | -50점 |
| 게임 클리어 | +500점 |

- 이동하지 못한 입력은 이동 횟수와 점수에 반영하지 않는다.
- 최종 점수는 0점보다 낮아지지 않는다.
- 점수는 스테이지마다 1,000점에서 시작한다.
- 결과 화면에는 해당 스테이지 점수, 이동 횟수, 수집 개수와 되감기 사용 횟수를 표시한다.
- 계정별로 각 스테이지의 최고 점수와 전체 최고 점수 합계를 저장한다.

## 5. 승리·실패 조건

### 승리

- 모든 시간 톱니바퀴를 획득한다.
- 열린 출구 타일에 도착한다.
- 현재 스테이지를 클리어하고, 다음 스테이지가 있으면 해금한다.
- 5번 스테이지를 클리어하면 전체 게임 완료로 처리한다.

### 실패

- 시간 균열 타일에 진입한다.

### 게임 종료 후

- 이동과 되감기 입력을 중지한다.
- 승리 또는 실패 결과와 플레이 기록을 표시한다.
- `다시 시작`과 `메인 화면` 버튼을 제공한다.
- 완료되거나 실패한 현재 스테이지의 임시 이어하기 데이터는 삭제한다.
- 스테이지 클리어 기록과 해금 정보는 유지한다.
- 승리 결과에는 `다음 스테이지`, `다시 도전`, `스테이지 선택` 버튼을 제공한다.
- 마지막 스테이지 승리 결과에는 `다음 스테이지` 대신 `전체 결과 보기`를 제공한다.

## 6. 로그인과 계정

게임을 처음 열면 로그인 화면을 먼저 표시한다. 계정은 서버에 가입하는 방식이 아니라 현재 브라우저에 로컬 프로필을 만드는 방식이다.

### 계정 만들기

1. `새 계정 만들기`를 선택한다.
2. 2~12자의 게임용 닉네임을 입력한다.
3. 숫자 4자리 PIN을 입력하고 한 번 더 확인한다.
4. 같은 닉네임이 없으면 로컬 계정을 생성하고 로그인한다.
5. PIN 원문은 저장하지 않고 브라우저 Web Crypto 기능으로 만든 해시와 임의의 salt만 저장한다.

### 로그인

1. 저장된 계정 목록에서 닉네임을 선택하거나 입력한다.
2. 4자리 PIN을 입력한다.
3. PIN 검증에 성공하면 해당 계정의 메인 화면으로 이동한다.
4. 실패하면 계정 존재 여부를 자세히 구분하지 않고 `닉네임 또는 PIN을 확인하세요`라고 표시한다.

### 로그아웃과 계정 관리

- 메인 화면과 게임 화면에 현재 닉네임을 표시한다.
- `로그아웃`을 누르면 게임 입력을 중지하고 로그인 화면으로 돌아간다.
- 플레이 중 로그아웃하면 현재 진행을 먼저 자동 저장한다.
- 페이지를 새로 열면 보안을 위해 다시 PIN을 입력해 로그인한다.
- 계정 삭제는 PIN을 다시 확인하고 경고창에 동의한 경우에만 실행한다.
- 계정 삭제 시 해당 계정의 진행 저장, 튜토리얼 상태와 설정도 함께 삭제한다.

## 7. 메인 화면

메인 화면은 게임을 시작하거나 기존 진행을 이어갈 수 있는 진입 화면이다.

### 구성 요소

| 요소 | 역할 |
|---|---|
| 게임 제목과 한 줄 설명 | 게임의 분위기와 목표 전달 |
| 현재 계정 | 로그인한 닉네임 표시 |
| `새 게임` 버튼 | 저장 데이터와 무관하게 처음부터 시작 |
| `이어하기` 버튼 | 저장된 진행 상황 불러오기 |
| `스테이지 선택` 버튼 | 해금된 스테이지와 최고 점수 확인 및 선택 |
| `조작법` 버튼 | 조작법과 핵심 규칙을 모달로 표시 |
| `저장 기록 삭제` 버튼 | 저장된 진행 상황 삭제 |
| 음소거 버튼 | 배경음과 효과음 함께 켜기·끄기 |
| `로그아웃` 버튼 | 현재 계정을 종료하고 로그인 화면으로 이동 |
| `계정 삭제` 버튼 | PIN 재확인 후 현재 로컬 계정과 데이터 삭제 |

### 버튼 표시 규칙

- 유효한 저장 데이터가 있을 때만 `이어하기`와 `저장 기록 삭제` 버튼을 활성화한다.
- 저장 데이터가 없으면 `이어하기`를 숨기거나 비활성화하고 `저장된 게임 없음`을 표시한다.
- `새 게임`을 눌렀을 때 기존 저장이 있으면 덮어쓸지 한 번 확인한다.
- `새 게임`은 스테이지 진행도까지 삭제하는 것이 아니라 1번 스테이지의 새 플레이를 시작한다.
- 전체 해금 기록을 지우려면 별도의 `진행도 초기화` 확인 기능을 사용한다.

## 8. 스테이지 선택 화면

- 1번부터 5번까지의 스테이지 카드를 표시한다.
- 해금된 스테이지는 이름, 최고 점수와 클리어 여부를 보여준다.
- 잠긴 스테이지는 자물쇠 상태로 표시하고 선택할 수 없다.
- 현재 진행 중인 임시 저장이 있으면 해당 스테이지 카드에 `진행 중` 표시를 한다.
- 해금된 스테이지를 선택하면 새로 시작할지 해당 임시 저장을 이어갈지 선택한다.

## 9. 조작법 화면

메인 화면에서 `조작법` 버튼을 누르면 페이지 이동 없이 모달을 연다.

| 입력 | 기능 |
|---|---|
| 방향키 또는 WASD | 상하좌우로 한 칸 이동 |
| `R` | 모래시계 1개를 사용해 기준점으로 되감기 |
| 화면 방향 버튼 | 모바일에서 상하좌우 이동 |
| 화면 되감기 버튼 | 모바일에서 시간 되감기 |
| 저장 버튼 | 현재 진행 상황을 브라우저에 저장 |

조작법 모달에는 톱니바퀴, 모래시계, 기준점, 출구와 시간 균열의 의미도 함께 표시한다. 닫기 버튼, 모달 바깥 클릭 및 `Esc`키로 닫을 수 있게 한다.

## 10. 게임 시작 튜토리얼

계정에서 처음으로 1번 스테이지를 시작하면 실제 맵 위에 단계별 튜토리얼을 표시한다. 튜토리얼 동안 강조된 행동 외의 입력은 제한한다.

| 단계 | 안내 내용 | 완료 조건 |
|---:|---|---|
| 1 | 방향키 또는 WASD로 이동하세요. | 플레이어가 한 칸 이동 |
| 2 | 빛나는 톱니바퀴를 모으세요. | 첫 톱니바퀴 획득 |
| 3 | 모래시계는 되감기 횟수와 기준점을 제공합니다. | 첫 모래시계 획득 |
| 4 | `R`키 또는 되감기 버튼을 사용하세요. | 되감기 1회 실행 |
| 5 | 모든 톱니바퀴를 모으면 출구가 열립니다. | 안내 확인 |

### 튜토리얼 원칙

- `다음`, `건너뛰기` 버튼을 제공한다.
- 모바일에서는 현재 단계에 필요한 화면 버튼을 함께 강조한다.
- 한 번 완료하거나 건너뛰면 브라우저에 완료 여부를 저장한다.
- 이후 새 게임에서는 튜토리얼을 자동으로 띄우지 않되 설정 또는 조작법 화면에서 다시 볼 수 있게 한다.
- 이어하기를 선택하면 저장된 게임으로 바로 복귀하며 튜토리얼을 강제로 다시 시작하지 않는다.

## 11. 저장 및 이어하기

### 저장 방식

- 브라우저의 `localStorage`에 JSON 형태로 저장한다.
- 계정 생성 시 고유한 사용자 ID를 발급하고 저장 데이터는 사용자 ID별로 분리한다.
- 같은 브라우저 안에서도 A 계정은 B 계정의 이어하기 기록을 볼 수 없다.
- 서버로 데이터를 전송하지 않는다.
- 저장 데이터는 같은 브라우저와 같은 기기에서만 사용할 수 있다.
- 브라우저 데이터 삭제, 시크릿 모드 종료 또는 다른 주소로 접속하면 저장 기록이 사라질 수 있다.

### 저장 시점

- 게임 화면의 `저장` 버튼을 눌렀을 때 수동 저장한다.
- 정상 이동, 아이템 획득, 되감기 및 출구 개방 후 자동 저장한다.
- 저장 성공 시 `저장되었습니다`라는 짧은 메시지를 표시한다.

### 저장 항목

- 저장 데이터 버전
- 현재 맵 상태
- 플레이어 위치
- 시간 기준점
- 점수와 이동 횟수
- 톱니바퀴 수집 개수
- 되감기 보유 및 사용 횟수
- 출구 개방 여부
- 선택 기능이 추가된 경우 열쇠와 무너진 발판 상태
- 저장 데이터를 소유한 사용자 ID
- 현재 스테이지 ID
- 해금된 최고 스테이지 번호
- 스테이지별 클리어 여부와 최고 점수

### 저장하지 않는 항목

- 현재 재생 중인 애니메이션
- 일시적인 안내 문구
- 열린 모달 상태
- 키보드를 누르고 있는 상태

### 이어하기 규칙

1. 메인 화면을 열 때 저장 데이터 존재 여부를 확인한다.
2. 현재 로그인한 사용자 ID와 일치하는 저장 데이터만 찾는다.
3. 데이터 구조와 필수 값이 정상일 때 `이어하기`를 활성화한다.
4. 이어하기를 누르면 저장된 스테이지의 맵과 플레이어 상태를 복원한다.
5. 복원 후 게임 상태는 `PLAYING`이 된다.
6. 저장 데이터가 손상되었거나 다른 계정의 데이터이면 불러오지 않고 새 게임을 안내한다.

### 계정별 저장 예시

| 계정 | 개별 저장 항목 |
|---|---|
| 사용자 A | 게임 진행, 튜토리얼 완료 여부, 음소거·음량 설정 |

## 14. 시간이 남으면 추가할 기능

### 우선순위 1

- 되감기 잔상 애니메이션
- 출구 개방 및 아이템 획득 애니메이션
- 저장 시간 표시

### 우선순위 2

- 스테이지별 별 1~3개 평가

- 실제 이동 경로를 역순으로 보여주는 되감기 연출
- 계정별 최고 점수와 플레이 통계
- 계정 데이터 내보내기·가져오기

여러 수동 저장 슬롯은 데이터 구조가 복잡해지므로 계정별 단일 진행 저장이 완성된 뒤 추가한다.

### 사운드 재생 원칙

- 배경음악은 한 번에 한 곡만 재생한다.
- 화면 또는 스테이지가 변경되면 기존 배경음을 멈추고 해당 배경음으로 교체한다.
- 스테이지 클리어·실패 효과음이 재생될 때 배경음 볼륨을 잠시 낮춘다.
- 전체 완료 화면에서는 5번 스테이지 배경음을 멈추고 `bgm-all-clear.mp3`를 재생한다.
- 5번 스테이지 완료 시 `all-clear.mp3`를 먼저 재생하고, 약 1초 뒤 `bgm-all-clear.mp3`를 낮은 볼륨으로 시작한다.
- 발걸음 2종은 번갈아 재생한다.
- 모래시계 획득 시 `collect-hourglass.mp3`를 먼저 재생하고 기준점 표시 애니메이션이 끝날 때 `time-anchor.mp3`를 재생한다.
- 자동 저장에는 저장음을 재생하지 않고 수동 저장 성공 시에만 재생한다.
- 모바일에서는 포인터 호버가 없으므로 `ui-hover.mp3`를 재생하지 않는다.
- 기본 음량은 배경음 35%, 효과음 70%를 권장한다.
- 음소거와 음량 설정은 로그인 계정별로 저장한다.
- 브라우저 자동 재생 제한에 따라 첫 클릭·터치·키 입력 전에는 음악을 강제로 재생하지 않는다.
- 이미지나 사운드 파일 로딩에 실패해도 게임 규칙과 조작은 정상적으로 작동해야 한다.

## 16. 프로젝트 완료 기준

- [ ] GitHub Pages에서 별도 설치 없이 실행된다.
- [ ] 닉네임과 PIN으로 로컬 계정을 생성하고 로그인할 수 있다.
- [ ] PIN 원문이 `localStorage`에 저장되지 않는다.
- [ ] 잘못된 PIN으로 로그인할 수 없다.
- [ ] 로그인한 닉네임이 메인 화면과 게임 화면에 표시된다.
- [ ] 로그아웃하면 로그인 화면으로 돌아간다.
- [ ] 두 계정을 만들었을 때 서로의 저장 기록과 설정이 섞이지 않는다.
- [ ] PIN 재확인 없이 계정을 삭제할 수 없다.
- [ ] 계정 삭제 시 해당 계정 데이터만 삭제된다.
- [ ] 메인 화면에서 새 게임, 조작법과 이어하기 기능을 확인할 수 있다.
- [ ] 5개 스테이지가 서로 다른 맵과 퍼즐로 구성된다.
- [ ] 처음에는 1번 스테이지만 선택할 수 있다.
- [ ] 스테이지를 클리어하면 다음 스테이지가 해금된다.
- [ ] 잠긴 스테이지는 직접 실행할 수 없다.
- [ ] 계정별 스테이지 해금과 최고 점수가 저장된다.
- [ ] 현재 저장이 어느 스테이지인지 표시되고 정확히 복원된다.
- [ ] 유효한 저장 데이터가 있을 때만 이어하기가 활성화된다.
- [ ] 조작법 모달을 열고 닫을 수 있으며 핵심 규칙이 모두 표시된다.
- [ ] 계정에서 처음 1번 스테이지를 시작하면 튜토리얼이 순서대로 진행된다.
- [ ] 튜토리얼을 완료하거나 건너뛴 뒤 자동 재등장하지 않는다.
- [ ] 방향키, WASD와 모바일 버튼으로 플레이할 수 있다.
- [ ] 톱니바퀴 수집, 모래시계 획득과 되감기가 정상 작동한다.
- [ ] 되감기 후에도 수집 상태와 출구 상태가 유지된다.
- [ ] 모든 톱니바퀴를 모으면 출구가 열리고 출구 도달 시 승리한다.

- [ ] 수동 및 자동 저장 후 같은 계정으로 로그인하면 이어서 플레이할 수 있다.
