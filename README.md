# 색깔 주문 맞추기

기획서와 설계서에 따라 만든 5단계 색깔 기억력 게임입니다. 제공된 이미지 5개와 음원 7개를 사용합니다.

## 실행

`index.html`을 Edge, Chrome 등 웹 브라우저에서 여세요. 별도 설치나 빌드가 필요하지 않습니다.

## 게임 방법

1. **게임 시작**을 누릅니다.
2. 반짝이는 색깔 순서를 기억합니다. 표시 중에는 입력이 차단됩니다.
3. 마우스·터치 또는 숫자 키 **1(빨강), 2(파랑), 3(초록)**으로 같은 순서를 입력합니다.
4. 성공할 때마다 10점을 얻고, 다음 라운드에는 길이가 하나 늘어난 새로운 패턴이 나옵니다. 이전 패턴을 그대로 이어 붙이지 않습니다.
5. 5단계를 모두 성공하면 50점으로 승리합니다. 오답이면 획득한 점수를 유지하고 종료합니다.
6. **다시 하기**는 점수와 진행 상태를 초기화하고 시작 화면으로 돌아갑니다.

시간 제한은 없습니다. 최고 기록과 음소거 설정은 현재 브라우저에 저장됩니다. 다른 PC나 브라우저로 자동 동기화되지 않습니다. 저장소나 음원 사용이 차단되어도 기본 게임은 진행할 수 있습니다.

1라운드는 무작위 색깔 하나, 2라운드는 아직 나오지 않은 두 색깔이 무작위 순서로 나옵니다. 따라서 2라운드의 패턴 표시까지 진행하면 세 색깔이 모두 등장합니다. 3~5라운드는 매 라운드 세 색깔을 모두 포함합니다. 1라운드에서 오답으로 종료하면 세 색깔이 모두 나오기 전에 끝날 수 있습니다.

## 파일

- `index.html`: 시작·플레이·결과 화면
- `style.css`: PC·모바일 화면과 버튼 강조 효과
- `game.js`: 상태 전환, 순서 생성·판정, 사운드와 기록 저장
- `Images/`: 제공된 배경·팔레트·전구·승리·실패 이미지
- `Sounds/`: 제공된 배경음악·색깔별 효과음·정답·실패·승리음
- `Docs/`: 원본 기획 및 설계 문서

## GitHub Pages 배포

`index.html`, `style.css`, `game.js`, `Images/`, `Sounds/`를 같은 저장소 루트에 올리고 GitHub Pages의 게시 대상을 해당 브랜치 루트로 설정하면 됩니다. 경로의 대소문자를 유지하세요. 이 작업에서는 온라인 배포를 수행하지 않았습니다.

## 검증

Edge 기반 브라우저 자동 검사에서 시작부터 5단계 승리, 중간 오답·점수 유지, 입력 차단, 반복 재시작, 키보드 조작, 음소거, 기록 저장, 음원·저장소 실패 처리를 확인했습니다. 1366px PC 및 390/360/320px 모바일 화면에서 가로 넘침과 주요 버튼 배치를 확인했습니다. 실제 모바일 기기 및 Safari의 사운드 재생은 별도 확인이 필요합니다.
